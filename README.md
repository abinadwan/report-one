# RetailPulse | نبض المبيعات

واجهة تجريبية عربية (RTL) لعرض مؤشرات المبيعات، مع صفحة مستقلة لبناء جداول بيانات محلية وإضافة سجلات إليها. المشروع عبارة عن موقع ثابت يعتمد على HTML وCSS وJavaScript، ولا يتطلب خادمًا لتشغيل الواجهة.

## الصفحات

- **لوحة التحكم — `index.html`:** تعرض مؤشرات مبيعات ورسمًا بيانيًا وتوصيات توضيحية، وتوفر زر **بناء قاعدة البيانات** للانتقال إلى `db.html`، مع إمكانية التبديل بين المظهرين الفاتح والداكن.
- **بناء قاعدة البيانات — `db.html`:** إنشاء جداول بأعمدة نصية أو رقمية أو تاريخية، وإدخال السجلات بسرعة عبر Enter، وتعديل الخلايا مباشرة، وإغلاق الجداول وإعادة فتحها، وتصديرها CSV أو JSON. تحتوي على رابط للعودة إلى لوحة التحكم وزر لتبديل المظهر.

> **تنبيه:** مؤشرات لوحة التحكم والبيانات البيانية والتوصيات المعروضة حاليًا تجريبية، وليست مستخرجة تلقائيًا من الجداول التي ينشئها المستخدم. واجهة رفع الملفات في لوحة التحكم أيضًا محاكاة وليست استيرادًا فعليًا إلى قاعدة البيانات.

## التشغيل

يمكن فتح `index.html` في متصفح حديث لاستخدام الواجهة محليًا. وبديلًا عن ذلك، يمكن نشر الملفات كموقع ثابت باستخدام GitHub Pages.

1. افتح `index.html` لعرض لوحة التحكم.
2. اضغط **بناء قاعدة البيانات** أو **قاعدة البيانات** للانتقال إلى `db.html`.
3. أدخل اسم الجدول وأسماء الأعمدة وأنواعها ثم اضغط **إنشاء وفتح الجدول**. لا يمكن إنشاء جدول ثانٍ حتى إغلاق الجدول المفتوح.
4. في **إدخال البيانات** اكتب في الصف الفارغ أسفل الجدول. اضغط **Enter** للانتقال إلى الحقل التالي، وعند آخر حقل يُحفظ الصف وتظهر خانات جديدة تلقائيًا.
5. لتعديل بيانات محفوظة، اضغط على الخلية، واكتب قيمتها ثم اضغط Enter أو انتقل إلى خلية أخرى. **Escape** يلغي التعديل.
6. اضغط **إغلاق الجدول** مع الحفاظ على السجلات، ثم اختره واضغط **فتح الجدول** للعودة إليه.
7. استخدم **تصدير CSV** أو **تصدير JSON** لحفظ الجدول على جهازك، ثم رابط **لوحة التحكم** للعودة إلى الصفحة الرئيسية.

تُحمّل الخطوط والأيقونات ومكتبة Chart.js في الصفحة الرئيسية من خدمات خارجية؛ قد تتأثر بعض عناصر العرض في حال عدم توفر اتصال بالإنترنت.

## هيكل المشروع

| المسار | الوظيفة |
| --- | --- |
| `index.html` | الصفحة الرئيسية |
| `style.css` | التنسيق العام ومتغيرات الثيم |
| `script.js` | الرسم البياني، تفاعلات الواجهة والثيم في لوحة التحكم |
| `db.html` | صفحة بناء الجداول وإدارة السجلات |
| `db.css` | تنسيق صفحة قاعدة البيانات وتجاوبها |
| `db.js` | التخزين والتحقق من أنواع الحقول، الترقيم التسلسلي، وترحيل بيانات الإصدار القديم |
| `builder.js` | محرر الجدول، التنقل بالكيبورد، التعديل المباشر، الجلسات والتصدير والثيم |
| `.github/workflows/static.yml` | نشر الموقع الثابت إلى GitHub Pages عند الدفع إلى `main` |

## التخزين والقيود

- تُحفظ بيانات الجداول في `localStorage` داخل المتصفح تحت المفتاح `retailpulse-db`. **هذه ليست قاعدة بيانات خادمية**؛ ولا توجد مزامنة بين الأجهزة أو حسابات مستخدمين.
- قد تضيع البيانات عند مسح بيانات الموقع أو تغيير المتصفح أو الجهاز. يمكن تصدير الجداول إلى CSV أو JSON، لكن **استيرادها واستعادة النسخة الاحتياطية عبر الواجهة غير متاحين بعد**.
- يُحفظ عداد ID رقمي مستقل ومتزايد لكل جدول، مع منع إعادة استخدام المعرف بعد إنشاء الصف.
- تُحفظ أنواع الأعمدة (نص، رقم، تاريخ) ويُتحقق من صحة المدخلات الجديدة والتعديلات.
- الجداول القديمة تُرحّل في الذاكرة مع حفظ النسخة الخام القديمة تحت المفتاح `retailpulse-db-backup-before-v2` قبل أول كتابة على قاعدة البيانات الجديدة. إذا كانت IDs القديمة نصية، تحفظ قيمها في `legacyId` مع تخصيص أرقام تسلسلية جديدة.
- لا توجد مزامنة بين علامات تبويب المتصفح؛ لا تعدّل البيانات نفسها من تبويبين في الوقت نفسه.
- لا تستخدم هذه النسخة لتخزين معلومات حساسة أو بيانات أعمال إنتاجية.

## النشر

يحتوي المشروع على GitHub Actions workflow في `.github/workflows/static.yml` لنشر الملفات إلى GitHub Pages بعد الدفع إلى الفرع `main` (أو تشغيل الإجراء يدويًا). يتطلب النشر إعداد GitHub Pages والصلاحيات المناسبة داخل المستودع.

## حالة المشروع

نسخة أولية قيد التطوير. يتوفر تعديل الخلايا والتصدير، وما زال مطلوبًا لاحقًا: حذف السجلات والبحث، واستيراد النسخ الاحتياطية، وربط الجداول الفعلية بلوحة التحكم والتقارير، واختبارات متصفح آلية كاملة.
